# DPP Prototype

Clickable prototype for the capstone: a B2B SaaS app for managing Digital Product Passports with an AI evidence check. Built with shadcn/ui.

- `design-context/`: design context file (product, users, tone, rules)
- `payloads/`: mock data and AI check responses used by the screens
- `figma/`: node-id map of the Figma screens and exported screenshots
- `app/`: code for the prototype (later phase)

Figma source: Capstone file, page "Design".
